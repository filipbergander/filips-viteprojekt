Hur publicerade jag hemsidan med VITE?

  1. Jag har node.js nedladdat på min dator sedan tidigare.
  2. För att börja skapa hemsidan skrev jag i terminalen för windows: npm create vite@latest.
  3. Jag valde projekt-namn -> framework till vanilla, variant till javascript -> nej till experimentella funktioner -> installera med npm och starta nu.
  4. Jag startade VSC med code . -> La in node-modules/ inom .gitignore.-> uppladdning till github som publikt repo.
  5. Deletade övriga bilder och filer som fanns sedan innan inom public och src.
  6. Inom min index.html länkade jag in css- och javascript-filer.
  7. Skapade vite.config.js för att lägga till sidor inom (html) när man kör npm run build, utan detta blir bara index.html lagd till dist
  8. Kopplade github repo till Netlify för publicering av hemsidan, -> valde att deploya branch dev först för att kika.
